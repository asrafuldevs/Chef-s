# Chef-s

Chef-s is a React-based recipe app where users can browse recipes, add items to a **Want to Cook** list, and move selected items to a **Currently Cooking** list.

## Live Link

[Visit Chef-s Live](https://asrafuldevs.github.io/Chef-s/)

## Features

- Browse recipe cards with image, ingredients, cooking time, and calories
- Add recipes to a cooking queue
- Move recipes from queue to currently cooking/completed section
- Clean and responsive UI using Tailwind CSS and DaisyUI

## Tech Stack

- React
- Vite
- Tailwind CSS
- DaisyUI

## Run Locally

1. Clone the repository
2. Install dependencies:

```bash
npm install
```

3. Start development server:

```bash
npm run dev
```

4. Build for production:

```bash
npm run build
```
